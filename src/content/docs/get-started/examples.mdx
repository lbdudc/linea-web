[`lbdudc/linea-examples`](https://github.com/lbdudc/linea-examples) holds example lines. Its `calculator-examples/` folder is a calculator web app whose products choose the operations they have. It brings everything the example is made of:

| Folder | What it holds |
|---|---|
| `metamodels/` | `common`, `basic` (the product's name, version, languages and package) and `featuremodel` |
| `modules/` | The four calculator modules (below) |
| `examples/` | A line of each kind, each with a product: `spl-calculator` (plain), `project-calculator` (project) and `modular-calculator` (modular) |

| Module | Offers |
|---|---|
| `basic-module` | display, numeric keyboard, clear and the REST service that the operations fill in |
| `basic-operations-module` | `add`, `subtract`, `multiply` |
| `capabilities-module` | `decimal` numbers |
| `advanced-operations-module` | `divide`, `power`, `square_root` (`divide` and `square_root` require `decimal`) |

| Line | Kind | Product |
|---|---|---|
| `spl-calculator` | plain: its own annotated platform and feature model | `spl-product`: add, subtract, multiply, divide and decimal numbers |
| `project-calculator` | project: the same platform, and the metamodel `basic` to describe each product | `project-product`: add, subtract and multiply, named "Project calculator" |
| `modular-calculator` | modular: made of the four modules | `modular-product`: every operation, named "Modular calculator" |

<Aside type="note" title="What you need">
Docker with Compose, and the two repositories side by side. This page continues from the [Quickstart](/get-started/quickstart/); the only difference is that the calculator is loaded into LINEA when it starts.
</Aside>

## 1. Start LINEA with the example

<Steps>

1. **Clone both repositories** into the same folder.

   ```bash
   git clone https://github.com/lbdudc/linea
   git clone https://github.com/lbdudc/linea-examples
   ```

2. **Start the stack** with the example's Compose file. It mounts `calculator-examples/modules` and `calculator-examples/examples` into the server's registry. At start the server publishes the modules into the `local` git host, and makes a repository for each example line and each of its products in the group `examples`.

   ```bash
   cd linea/deploy
   cp .env.example .env     # change JWT_SIGN_KEY and LINEA_ADMIN_PASSWORD
   EXAMPLES_DIR=$(cd ../../linea-examples && pwd) \
     docker compose -f docker-compose.yml -f ../../linea-examples/docker-compose.linea.yml up -d
   ```

3. **Open** [http://localhost:9000](http://localhost:9000) and sign in as `admin`.

</Steps>

The modules are listed because `.env.example` sets `LINEA_REGISTRY=local:registry/index`. With another registry, see [the package registry](/configure/registry/). Starting again leaves the lines alone: a line that is already there is not made again.

## 2. Look at the lines and generate a product

<Steps>

1. Open **Modules** and check that the four calculator modules are there.
2. Open **Lines**: the three example lines are listed. `modular-calculator` shows its modules in the **Modules** tab, and `project-calculator` its metamodels in **Metamodels**.
3. Open a line's product, for example `modular-product`, and check its models and its feature selection. The tree rejects `divide` without `decimal`.
4. Click **Generate product**, follow it in **Versions & syncs** and merge the `bigbang → main` request.

</Steps>

To build a line of your own from the modules, open **Lines → Create SPL**, choose the kind **Modular** and add them. The advanced and basic operations modules declare `basic-module` as a requirement; add it too if the line does not.

## Other hosts and from source

- **GitLab or GitHub**: publish the metamodels, the modules and the example lines into your group or organisation with the server's script, once. On GitHub:

  ```bash
  cd linea/apps/server
  GITHUB_TOKEN=<token with repo scope> node scripts/publish-registry.mjs --host github --owner <user or organisation> \
    --dir ../../../linea-examples/calculator-examples --registry github:<owner>/linea-registry
  ```

  Then start the server with `LINEA_REGISTRY=github:<owner>/linea-registry` and `LINEA_FEATURE_METAMODEL=github:<owner>/featuremodel`, and sign in: the example lines are listed the first time LINEA is opened. For GitLab, see [the package registry](/configure/registry/#publish-the-sample-registry).
- **From source**: set `REGISTRY_DIR` to `<linea-examples>/calculator-examples` and `LINEA_REGISTRY=local:registry/index` in `apps/server/.env`.
